## Have you encountered any system problem(s) when testing? How did you attempt to correct the problem(s)?

Yes, we encountered several dependency conflicts when testing:

1. First issue: Incompatibility between Flask-Login and Werkzeug
   - Error: "ImportError: cannot import name 'url_decode' from 'werkzeug.urls'"
   - Solution: Pinned Flask to 2.0.1, Werkzeug to 2.0.3, and Flask-Login to 0.5.0

2. Second issue: SQLAlchemy compatibility problem
   - Error: "AttributeError: module 'sqlalchemy' has no attribute '__all__'"
   - Solution: Explicitly specified SQLAlchemy version 1.4.46 to work with Flask-SQLAlchemy 2.5.1

3. Docker/Docker Compose availability
   - Error: "docker-compose: The term 'docker-compose' is not recognized..."
   - This suggests Docker or Docker Compose is not installed or not in the PATH
   - Solution would be to install Docker Desktop or Docker Engine with Docker Compose
